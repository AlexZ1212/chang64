# chang64

A free, bilingual (EN/FR) chess website. Live at **https://chang64.com**

This repository has two parts:

- **[`chang64-site/`](chang64-site/)** — the site itself: the engine, the interface, the
  1,353 static content pages, and the licence. Start there. Its own
  [README](chang64-site/README.md) covers what the site does, the licence split between
  code (GPL v3) and editorial content, and the Stockfish attribution.

- **[`design-system/`](design-system/)** — the visual identity handoff: design tokens,
  chess piece artwork, the elephant mark, and the specification document. Reference
  material for anyone adapting the site's look, not code to run as-is. See its own
  [README](design-system/README.md) for the full specification.
